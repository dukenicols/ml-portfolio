# 01 — EDA Portfolio

A small, reusable exploratory-data-analysis toolkit, exercised against two
datasets built into scikit-learn: **wine** (classification, 3 cultivars) and
**diabetes** (regression). No downloads, no API keys — both load from memory
in under a second, so the whole run finishes in seconds on a CPU.

The point isn't the datasets, it's the EDA functions in `eda_portfolio/eda.py`:
missing-value reporting, outlier detection (Tukey's IQR rule), pairwise
correlation ranking, and class-balance checks — the checks I'd run first on
any new tabular dataset, written once and unit-tested instead of copy-pasted
into a notebook each time.

## How to run

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python3 run_eda.py        # writes results/eda_report.md and results/*.csv
pytest tests/ -v          # 10 tests
```

`run_eda.py` prints every number below and writes it to `results/`, so the
report is reproducible from a single command.

## What I'd check next

- `s1`/`s2` correlating at 0.90 in the diabetes set is a flag for a future
  regression post: with collinearity that strong, a plain linear model needs
  regularization (ridge/lasso) or one of the two features dropped.
- The outlier counts here are Tukey's IQR rule, which flags ~0.7% of a normal
  distribution by chance — some of what's counted is normal spread, not bad
  data. A model-building post on either dataset should look at *why* a flagged
  point is extreme before dropping it.
