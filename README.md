# ml-portfolio

Twenty-two machine-learning projects, built one at a time and written up on
[nicolasduque.com](https://nicolasduque.com/blog/). Each folder is self-contained:
its own `README.md`, `requirements.txt`, code, tests and the exact command that
reproduces the numbers quoted in the post.

I'm a full-stack engineer (React / Node.js / LLM integration). This repo is where
I work through classic and modern ML from first principles, in public. The
metrics in each README come from running the code in this repo — nothing is
copied from elsewhere.
